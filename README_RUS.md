# Agent Skills — Навыки для AI-агентов

Коллекция навыков (skills) для AI-агентов написания кода. Навыки — это упакованные инструкции и скрипты, расширяющие возможности агентов.

Навыки соответствуют формату [Agent Skills](https://agentskills.io/).

[![skills.sh](https://skills.sh/b/vercel-labs/agent-skills)](https://skills.sh/vercel-labs/agent-skills)

Использовать выборочно через UI в проекте: https://www.skills.sh/

## Доступные навыки

### react-best-practices

Рекомендации по оптимизации производительности React и Next.js от команды Vercel Engineering. Содержит 40+ правил в 8 категориях, упорядоченных по приоритету влияния.

**Использовать когда:**

- Пишете новые React-компоненты или страницы Next.js
- Реализуете загрузку данных (на клиенте или сервере)
- Ревьюите код на предмет проблем с производительностью
- Оптимизируете размер бандла или время загрузки

**Охватываемые категории:**

- Устранение водопадов (критично)
- Оптимизация размера бандла (критично)
- Производительность на сервере (высокий приоритет)
- Загрузка данных на клиенте (средне-высокий приоритет)
- Оптимизация повторных рендеров (средний приоритет)
- Производительность рендеринга (средний приоритет)
- Микрооптимизации JavaScript (низко-средний приоритет)

### web-design-guidelines

Проверка UI-кода на соответствие лучшим практикам веб-интерфейсов. Аудит по 100+ правилам: доступность, производительность и UX.

**Использовать когда:**

- «Проверь мой UI»
- «Проверь доступность»
- «Аудит дизайна»
- «Проверь UX»
- «Сравни мой сайт с лучшими практиками»

**Охватываемые категории:**

- Доступность (aria-labels, семантический HTML, обработчики клавиатуры)
- Состояния фокуса (видимый фокус, паттерны focus-visible)
- Формы (автозаполнение, валидация, обработка ошибок)
- Анимации (prefers-reduced-motion, трансформации через compositor)
- Типографика (фигурные кавычки, многоточие, tabular-nums)
- Изображения (размеры, ленивая загрузка, alt-текст)
- Производительность (виртуализация, layout thrashing, preconnect)
- Навигация и состояние (URL отражает состояние, deep-linking)
- Тёмная тема и оформление (color-scheme, theme-color meta)
- Касания и взаимодействие (touch-action, tap-highlight)
- Локализация и i18n (Intl.DateTimeFormat, Intl.NumberFormat)

### react-native-guidelines

Лучшие практики React Native, оптимизированные для AI-агентов. 16 правил в 7 разделах: производительность, архитектура и платформо-специфичные паттерны.

**Использовать когда:**

- Разрабатываете приложения на React Native или Expo
- Оптимизируете мобильную производительность
- Реализуете анимации или жесты
- Работаете с нативными модулями или платформенными API

**Охватываемые категории:**

- Производительность (критично) — FlashList, мемоизация, тяжёлые вычисления
- Лейаут (высокий) — flex-паттерны, безопасные зоны, обработка клавиатуры
- Анимации (высокий) — Reanimated, обработка жестов
- Изображения (средний) — expo-image, кэширование, ленивая загрузка
- Управление состоянием (средний) — паттерны Zustand, React Compiler
- Архитектура (средний) — монорепо, импорты
- Платформа (средний) — паттерны iOS/Android

### react-view-transitions

Реализация плавных нативных анимаций через View Transition API React. Охватывает компонент `<ViewTransition>`, `addTransitionType`, типы переходов и интеграцию с Next.js, включая проп `transitionTypes` у `next/link`.

**Использовать когда:**

- Добавляете переходы между страницами или анимации маршрутов
- Анимируете появление/исчезновение компонентов
- Создаёте переходы с общими элементами (морфинг список→детали)
- Реализуете направленную навигацию (вперёд/назад)
- Интегрируете view transitions в Next.js App Router
- Анимируете переупорядочение списков или раскрытие Suspense-заглушек

**Охватываемые темы:**

- Компонент `<ViewTransition>` (триггеры enter, exit, update, share)
- `addTransitionType` для направленных/контекстных анимаций
- Классы View Transition и CSS псевдоэлементы
- Переходы с общими элементами через проп `name`
- JavaScript-анимации через Web Animations API
- Проп `transitionTypes` у `next/link` в Next.js
- Готовые CSS-рецепты анимаций (fade, slide, scale, flip)
- Доступность (`prefers-reduced-motion`)

### composition-patterns

Паттерны композиции React, масштабируемые на больших проектах. Помогает избежать размножения булевых пропов через compound-компоненты, подъём состояния и внутреннюю композицию.

**Использовать когда:**

- Рефакторите компоненты с множеством булевых пропов
- Строите переиспользуемые библиотеки компонентов
- Проектируете гибкие API
- Ревьюите архитектуру компонентов

**Охватываемые паттерны:**

- Выделение compound-компонентов
- Подъём состояния для сокращения пропов
- Компоновка внутренностей для гибкости
- Избегание prop drilling

### vercel-deploy-claimable

Мгновенный деплой приложений и сайтов на Vercel. Создан для использования с claude.ai и Claude Desktop — позволяет деплоить прямо из разговора. Деплойменты «заявляемые» — пользователь может перенести владение на свой аккаунт Vercel.

**Использовать когда:**

- «Задеплой моё приложение»
- «Выложи это на продакшн»
- «Запуши в прод»
- «Задеплой и дай ссылку»

**Возможности:**

- Автоопределение 40+ фреймворков из `package.json`
- Возвращает preview URL (живой сайт) и claim URL (передача прав)
- Автоматически обрабатывает статические HTML-проекты
- Исключает `node_modules` и `.git` из загрузки

**Как работает:**

1. Упаковывает проект в tarball
2. Определяет фреймворк (Next.js, Vite, Astro и др.)
3. Загружает на сервис деплоя
4. Возвращает preview URL и claim URL

**Пример вывода:**

```
Deployment successful!

Preview URL: https://skill-deploy-abc123.vercel.app
Claim URL:   https://vercel.com/claim-deployment?code=...
```

## Использование — пошаговая инструкция

### Шаг 1. Установите навыки

```bash
npx skills add vercel-labs/agent-skills
```

После установки навыки автоматически становятся доступны агенту.

### Шаг 2. Запустите агента и напишите задачу

Агент сам определит, какой навык применить, на основе вашего запроса.

**Примеры запросов:**

```
Задеплой моё приложение
```

```
Проверь этот React-компонент на проблемы с производительностью
```

```
Помоги оптимизировать эту страницу Next.js
```

### Шаг 3. Агент применяет нужный навык

- Если запрос связан с деплоем → активируется `vercel-deploy-claimable`
- Если запрос о React/Next.js → активируется `react-best-practices`
- Если запрос об UI или доступности → активируется `web-design-guidelines`
- Если запрос о React Native → активируется `react-native-guidelines`

### Шаг 4. Получите результат

Агент выполнит задачу и вернёт результат согласно инструкциям из навыка (URL деплоя, ревью кода, список замечаний и т.д.).
